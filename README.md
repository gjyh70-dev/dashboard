# 국방예산 대시보드

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 인터넷 연결이나 별도 설치가 필요하지 않습니다.

- 부문, 회계구분, 프로그램 검색 조건을 함께 적용합니다.
- 8개 그래프, 4개 요약 지표, 정렬 가능한 상세 표를 제공합니다.
- 선택 데이터를 CSV로 내려받을 수 있습니다.
- 금액 단위는 억 원입니다. 음수는 차감 재원입니다.
- 구성비·예산 지도·규모 순위에는 양수 재원만 사용합니다. 예산 분포와 증가율 맵의 대상 기준은 각 차트에 표시했습니다.
- 증감률은 엑셀의 표시값을 전사하지 않고 원래 금액으로 계산합니다.

데이터: 상위 폴더 `프로그램별_재원.xlsx`의 32개 행을 반영한 정적 스냅샷입니다. 엑셀 수정 내용은 자동 반영되지 않습니다. `data.js`에 연도별 금액과 분류가 저장되어 있고 증감액과 증감률은 화면에서 계산합니다.

전력운영 상세 합계는 원문 총 재원과 2026년·2027년 각각 1억 원 차이가 있습니다. 원문 데이터를 유지했습니다.
